HTTP Header Analyzer

Explain and audit response headers

Paste a raw HTTP response or request header block. Each recognized header gets a one-line explanation, security-relevant headers are flagged as safe or weak, and a posture summary lists recommended security headers that are missing. Text only, nothing is fetched, nothing leaves this page.

Headers are parsed locally as plain text. No request is ever sent to any server.
